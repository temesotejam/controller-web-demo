# Controller Web Demo

PS4 / PS5コントローラを使ったスマホ操作系の仕様を、ブラウザ上で確認するための静的Webデモです。

## デモ内容

- Gamepad APIによる左右スティックY軸の表示
- L2 / R2アナログ入力の表示
- コントローラ未接続時の入力シミュレーター
- 画面上の疑似タッチパッド
- 上スワイプで推進速度を5%増加
- 下スワイプで推進速度を5%低下
- 上端から反対側の下端への対角スワイプで急停止
- コントローラ操作の有効化・無効化
- 手動・安定化手動・試験モードの選択
- 急停止状態と解除操作の確認

## 使い方

1. GitHub PagesまたはローカルのWebサーバーで`index.html`を開きます。
2. PS4 / PS5コントローラをPCまたはスマホへ接続します。
3. ブラウザ上でボタンを一度操作し、Gamepad APIへ認識させます。
4. 入力値が中立であることを確認し、「コントローラを有効化」を押します。
5. 疑似タッチパッドをマウスまたは指でスワイプし、推進速度と急停止判定を確認します。

## ローカル起動

静的ファイルだけで動作します。Pythonがある場合は次のコマンドで確認できます。

```bash
python -m http.server 8000
```

その後、ブラウザで`http://localhost:8000`を開きます。

## ブラウザ版の制約

DualShock 4 / DualSense中央タッチパッドの座標は、ブラウザのGamepad APIから取得できない場合があります。そのため、中央タッチパッドのジェスチャーは画面上の疑似タッチパッドで再現しています。Androidネイティブアプリ化する際は、実機の入力イベントを診断して割り当てを確定します。
