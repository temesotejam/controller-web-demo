# Controller Web Demo

PS4 / PS5コントローラを使ったスマホ操作系の仕様を、ブラウザ上で確認するための静的Webデモです。

## デモ内容

- Gamepad APIによる左右スティックY軸の表示
- L2 / R2アナログ入力の表示
- コントローラ未接続時の入力シミュレーター
- 画面上の疑似タッチパッド
- WebHIDによるDualSense実機タッチパッド座標の実験取得
- 上スワイプで推進速度を5%増加
- 下スワイプで推進速度を5%低下
- 上端から反対側の下端への対角スワイプで急停止
- コントローラ操作の有効化・無効化
- 手動・安定化手動・試験モードの選択
- 急停止状態と解除操作の確認

## 通常の使い方

1. GitHub PagesまたはローカルのWebサーバーで`index.html`を開きます。
2. PS4 / PS5コントローラをPCまたはスマホへ接続します。
3. ブラウザ上でボタンを一度操作し、Gamepad APIへ認識させます。
4. 入力値が中立であることを確認し、「コントローラを有効化」を押します。
5. 疑似タッチパッドをマウスまたは指でスワイプし、推進速度と急停止判定を確認します。

## DualSense実機タッチパッドの試し方

WebHID機能は、まずWindows PCとDualSenseのUSB接続で確認してください。

1. データ通信対応のUSBケーブルでDualSenseをPCへ接続します。
2. GitHub PagesをChromeまたはEdgeで開きます。
3. 「DualSenseへWebHID接続」を押します。
4. 表示されたデバイス選択画面で`Wireless Controller`を選び、接続を許可します。
5. タッチパッドへ触れ、X・Y座標と緑色のマーカーが動くことを確認します。
6. 実機タッチパッドを上下または対角にスワイプし、推進速度と急停止判定を確認します。

DualSenseのUSB Vendor IDは`0x054c`、Product IDは`0x0ce6`です。このデモはUSB入力レポート`0x01`を主対象とし、Bluetooth入力レポート`0x31`も実験的に解析します。

## ローカル起動

静的ファイルだけで動作します。Pythonがある場合は次のコマンドで確認できます。

```bash
python -m http.server 8000
```

その後、ブラウザで`http://localhost:8000`を開きます。

WebHIDはセキュアコンテキストでのみ利用できます。GitHub PagesのHTTPSでは利用できます。ローカル開発では`localhost`がセキュアコンテキストとして扱われます。

## ブラウザ版の制約

通常のGamepad APIからはDualSense中央タッチパッドの座標を取得できません。そのため、WebHID非対応環境向けに画面上の疑似タッチパッドも残しています。

WebHIDは主にChrome / EdgeなどChromium系ブラウザ向けです。ブラウザ、OS、USB / Bluetooth接続方式、DualSenseのファームウェアによって入力レポートの公開状態が異なる可能性があります。取得できない場合も、画面には受信したレポートIDとバイト数が表示されるため、実機調査に利用できます。
