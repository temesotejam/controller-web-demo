# WebHID implementation sources

The report layout used by this demo follows the Linux `hid-playstation` DualSense input report structures and the `nondebug/dualsense` report documentation.

- Linux kernel: `drivers/hid/hid-playstation.c`
- DualSense report notes: `github.com/nondebug/dualsense`
- WebHID API: Chrome / MDN documentation
